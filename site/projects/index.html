Pi0.5 VLA on Dragonwing NPU

A vision-language-action model running on edge NPUs

I deployed the Pi0.5 vision-language-action model across dual Dragonwing NPUs and published the work as a Qualcomm tutorial. On LIBERO-10 it reaches 86/100 task success.

Mixed quantization cut latency per action chunk from 4421 ms to 1111 ms. Each chunk takes 15 sequential NPU calls. The result is one 50-action chunk about every 1.1 s, which is about 4.5x real time at 10 Hz. The runtime is C++ against the QNN API.

I showed it at ROSCon in September 2026, running fully on the IQ9 EVK NPU with GPU simulation.

PCB Agent

Circuit boards designed end to end by an AI agent

pcb-agent is an agent workflow that designs a circuit board end to end: parts, netlist, placement, routing, and fab-ready Gerbers. My job is review. It is packaged as a Claude Code plugin with /new-board, /build, /route, /check, and /doctor.

The design lives in a CSV, not in KiCad. One row per pin. Scripts build the schematic and the board from it, and the build passes are idempotent, so a respin takes hours, not days. Then five levels of checking, the last of which parses the exported Gerbers and drill files directly. Two human sign-off gates stop hallucinated pinouts.

The example board in the repo is a power and I/O shield for the Arduino UNO Q: 49 components on four layers, routed to 0 unconnected and 0 clearance violations. I have manufactured 6 board designs with this pipeline.

The companion tool is gerber-check, MIT licensed with zero dependencies. It catches what passes ERC and DRC but still ships a broken board.

FIRST Agentic CSA

AI-powered FRC documentation search

FIRST Agentic CSA is an open-source MCP server that gives FRC teams a single, trustworthy place to search across the entire documentation ecosystem. Instead of hopping between WPILib, REV, CTRE Phoenix 6, Redux Robotics, and PhotonVision, students can ask plain English questions and get documentation-grounded answers that respect the authoritative sources teams rely on during build season.

The project is designed to integrate directly with VS Code and AI coding assistants so that documentation lookups happen where teams already work. It works with GitHub Copilot, Cursor, and VS Code MCP. It filters by language (Java, Python, C++) and season year, and ships with a ready-to-drop copilot instructions file that nudges assistants to search docs before answering. The result is faster onboarding and fewer wrong answers. It has 3,000+ users and 16 releases, in an FRC community of 3,600+ teams working under intense time pressure.

    FRC Shooter Selector

    Ballistics analysis and optimization tool

    FRC Shooter Selector is a physics-first simulation toolkit for the 2026 REBUILT game that helps teams design shooter mechanisms before building expensive prototypes. It models full ballistics with quadratic drag on foam game pieces, then translates the physics into practical motor, gearing, and flywheel recommendations teams can implement quickly.

    The tool provides conservative torque calculations that avoid overheating, sensitivity analysis for angle and velocity errors, spin-up time comparisons across gear ratios, and flywheel mass tradeoff studies. Teams can use the browser-based app, a Django web interface, or the CLI for batch analysis. Outputs include Plotly charts, ready-to-copy RPM lookup tables, and PNG plots for design reviews.

    Rubik TFLite

    TFLite + libQnn on Qualcomm NPU

    Rubik TFLite is a hands-on demo that calls TensorFlow Lite using the libQnn delegate as an external delegate, defaulting to the HTP backend for QNN. I worked with a student to package the workflow so teams and developers can run on-device image transformation models without the usual setup friction.

    The project ships with C and Python demos that load input images from disk, run TFLite inference through QNN, and write outputs back to the filesystem. It targets image transformation models and highlights how to wire TFLite to Qualcomm hardware in a reproducible, student-friendly flow.

    Example runs use the Real-ESRGAN x4+ model from Qualcomm AI Hub and show end-to-end invocation with sample inputs and outputs. Supported input formats include JPEG, PNG, TGA, BMP, PSD, GIF, HDR, PIC, and PNM, with PNG output for easy inspection.
