Selected work

Read all write-ups

  • Pi0.5 VLA on Dragonwing NPU

    A vision-language-action model running on edge NPUs

    I deployed the Pi0.5 vision-language-action model across dual Dragonwing NPUs and published it as a Qualcomm tutorial. It reaches 86/100 task success on LIBERO-10. Mixed quantization cut latency per action chunk from 4421 ms to 1111 ms. Shown at ROSCon in September 2026, running fully on the IQ9 EVK NPU with GPU simulation. Read the tutorial.

    Built withC++, QNN, Hexagon NPU, quantization, LIBERO

  • PCB Agent

    Circuit boards designed end to end by an AI agent

    An agent workflow that designs a circuit board end to end: parts, netlist, placement, routing, and fab-ready Gerbers. It ships as a Claude Code plugin. The design lives in a CSV, scripts build the KiCad files from it, and five levels of checks run all the way to the fab output. I have manufactured 6 board designs with it. Read the full write-up.

    Built withPython, KiCad pcbnew API, Freerouting, Docker, Claude Code

  • FIRST Agentic CSA

    AI-powered FRC documentation search

    Open-source MCP server that lets AI assistants search FRC docs in plain English: WPILib, REV, CTRE Phoenix 6, Redux Robotics, and PhotonVision. 3,000+ users and 16 releases. Try the search.

    Built withPython, MCP Protocol, VS Code Integration
