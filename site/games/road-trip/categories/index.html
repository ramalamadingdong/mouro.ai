How it works

A word game for everyone in the car. It reads out a letter and a category (“C, things in a kitchen”), and you take turns naming one before the timer runs out. Stall and you’re out; the last one talking wins the round. No GPS needed: Categories never uses your location.

Car screen: one phone sits in a mount on the console, shows each turn big and reads it out, with a few big buttons anyone can tap. Passengers’ phones can join with its code as remotes. The room carries the word game only, never anyone’s location, and only phones with the code can see it.
