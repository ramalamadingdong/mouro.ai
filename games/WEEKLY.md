# Weekly cat games

Since November 2026 a new cat-themed multiplayer game is added here every
week. This file is the ledger of what exists, so that no game is repeated and
each week's pick comes from a different family of games than the last few.

Only the newest weekly game is shown on the games hub (`site/games/`, in its
"This week's game" spot). Earlier weekly games are hidden from the hub but
never removed: they keep their folder, server namespace, rules, Caddy route,
CI/deploy entries and tests, and stay playable at their own URL so invites
already sent keep working.
